# Pirce Watch

粘贴京东、淘宝／天猫商品链接，自动记录真实报价并绘制价格 K 线。页面没有手动录价功能，不预置商品或虚构历史。

浏览器采集部分改编自 [yuanbao15/YbPriceTracker](https://github.com/yuanbao15/YbPriceTracker)，固定版本 `fa09be5bd574b2ff991315a79b5305c2af036bce`。原 MIT 许可和具体修改在 `browser-extension/LICENSE`、`browser-extension/UPSTREAM.md`。

## 使用

需要 Node.js 24.15 或更新版本。运行本机服务不需要安装第三方依赖。

1. Windows 双击 `启动 Pirce Watch.cmd`，保持该窗口运行；也可执行 `npm start`。
2. 在日常使用的 Chrome 中打开 http://127.0.0.1:4173/ 。
3. 若要使用浏览器读价，点击“连接浏览器”，按说明安装扩展后刷新页面，点击“连接扩展”。Codex 内置预览浏览器不加载日常 Chrome 的扩展。
4. 在同一个 Chrome 中正常登录购物平台，选择商品规格，再把完整商品链接粘贴到网页添加关注。不需要填写价格。

扩展仅在有到期任务时打开后台商品标签，完成后关闭它自己创建的标签。扩展每分钟向本机检查任务；商品默认以 30 分钟为更新间隔。浏览器、扩展和本机服务都需要运行。登录失效或平台要求验证时，需要用户正常处理，程序不会自动解决验证码。

## 报价和历史

- 记录公开标价、官方公开展示价或商品页可见价，并保留时间、来源链接和价格口径。会员、领券、补贴、运费和库存需要在商品页核对。
- 淘宝／天猫结构化报价只取指定规格的“优惠前”标价，并核对分金额与元金额、库存和唯一规格映射；不把平台补贴价当作无条件到手价。该口径单独记录。
- 当前图表按同一种价格口径展示，避免将不同类型报价混在一条曲线中。
- 失败不会沿用旧价格伪造新记录。最后成功价格及时间会保留。
- 历史从首次成功采集开始，不回填。日 K、周 K、月 K 按北京时间聚合，周一为周起点，月初为月起点；缺失不插值，至少 7 个记录日后判断历史位置。记录低位不代表未来或全网最低。
- 目标价在成功采集后检查，提醒保存在网页内。

## 本机数据与权限

数据库和扩展连接授权仅存本机 `var/`。扩展使用浏览器自身的正常登录状态，不读取或导出电商 Cookie，不发送账号、密码、页面全文或浏览历史。扩展只具有指定官方商品页和本机服务的权限，令牌不经过网页、源码或日志。

本站通过自有会话 Cookie 区分关注列表。不同浏览器、设备和站点地址不会自动同步。清除该会话 Cookie 后，当前浏览器无法直接找回原列表。每个浏览器身份最多关注 100 件商品。备份数据库前请停止服务。

`var/`、`.env`、数据库、浏览器资料和运行日志不得提交或上传。发布包只包含代码、许可和测试。改造过程中没有上传个人数据或登录状态。

## 开发与线上部署

`dist/` 是网页界面；`server.mjs` 提供本机服务；`server/providers.mjs` 是公开采价器；`server/extension-bridge.mjs` 提供仅限回环地址的配对桥；`browser-extension/` 是改编后的 Chrome 扩展。

```sh
npm test
node --test browser-extension/tests/*.test.mjs
```

测试使用生成的夹具验证错误路径和数据一致性，不是实时报价证据。

线上 Worker + D1 入口位于 `worker/`，数据库迁移位于 `drizzle/`。执行 `npm ci` 后可用 `npm run build` 构建。云端不读取本机 Chrome 或扩展授权；当前线上后台更新仅在访问／刷新时触发，不提供关闭网页后的无人值守保证。线上部署状态必须经过单独验收。

项目代码采用 MIT；第三方代码沿用各自许可。Lightweight Charts 的 Apache 2.0 和 NOTICE 位于 `dist/vendor/`。代码开源不代表取得电商数据的采集、展示或再分发许可。
