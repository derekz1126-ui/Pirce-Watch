# Pirce Watch 本机采集助手

此扩展基于 YbPriceTracker 的后台标签与 DOM 采集代码改造，来源和修改见 `UPSTREAM.md`，许可见 `LICENSE`。

## 安装与连接

1. 在项目根目录执行 `npm start`，保持本机服务运行。需要 Node.js 24.15 或更新版本，本机运行无需安装依赖。
2. 使用平时的 Chrome 或 Edge，打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，选择“加载已解压的扩展程序”，选中本目录。
3. 在**同一个正常浏览器**打开 `http://127.0.0.1:4173/`，通过页面中的扩展连接操作完成配对。Codex 内置预览浏览器无法加载此扩展。
4. 需要登录时，在这个浏览器的官方商品页自行登录、选择规格，再回到 Pirce Watch 检查。扩展不使用独立自动化登录窗口，不自动处理验证码。

扩展每分钟向本机询问到期任务；商品采集间隔由服务端控制，空队列不打开商品页。浏览器和本机服务需要保持运行。扩展仅关闭自己创建的后台商品标签，不关闭已有标签。

令牌仅存浏览器扩展的本地可信存储；不读取、导出或上传电商 Cookie、账号资料或浏览历史。发送字段限商品链接、标题、规格及受支持价格位置的快照；条件字段只包含预定义资格词，不发送其余父容器文字。真实商品页未给出可确认价格时不生成报价。

更新后在扩展管理页点击“重新加载”，并刷新本机页面。测试命令：`node --test browser-extension/tests/extension.test.mjs`。测试夹具不是实际平台采价成功证据。
